# 子项目 4：完整用户工作流规格

状态：已批准，待实施验证
依赖：子项目 1–3 的 API、来源活动和后台状态

## 目标

把现有 React 工作台收敛为可发现、可阅读、可操作的完整产品流程，覆盖首次引导、行业管理、概览、每日、知识、来源、研究、产物、任务和系统状态。

## 信息架构

- 首次引导：环境诊断、连接方式、行业创建、首次任务和结果确认。
- 行业管理：创建、切换、重命名、导入、导出、移入回收站和恢复；永久删除另行二次确认。
- 行业概览：知识模块、产业链有向图、来源/文档/实体/断言/事实数量及链接、质量与覆盖缺口。
- 每日情报：标题/类别/来源/时间排序，筛选、分页、全选、多选和可恢复删除；展示首次出现、升温/跟踪/降温/未解决、相比昨日变化和七日趋势。
- 知识与实体：按类别、地区、产业链端点和状态浏览；实体详情显示关系、证据和时间。
- 来源治理：候选、审查、监测、健康、缺口和手动添加。
- 研究与 Lab：直接生成、Agent 交接、断言复核、覆盖地图和长周期状态。
- 产物：周/月/季/半年/两年/五年报告、Markdown、引用、限制和可视化；每日简报同时导出无需服务器/CDN 的单文件 HTML。
- 任务中心：阶段日志、心跳、来源、取消、重试和恢复。
- 系统：Provider、后台 Worker、数据目录、版本、安全存储和诊断。

## UI 约束

- 正文默认不小于 16px，辅助文字不小于 14px；长文本行高不低于 1.6。
- 表单、列表、下拉菜单和触控目标支持键盘与 200% 缩放。
- 使用低饱和度、圆角、清晰层级和稳定间距；状态不能只靠颜色表达。
- 长页面拆为聚焦组件，避免当前压缩在单行 JSX 中的不可维护结构。
- Markdown 链接、引用和外部 URL 使用安全打开策略。
- Markdown 阅读器使用成熟开源解析链（`react-markdown`、GFM 和 HTML sanitize），支持目录、表格、代码块、引用回链、文内搜索和可视化 sidecar；不执行原始 HTML 或任意脚本。

## 便携简报与成品质量门

每日简报必须同时生成 Markdown 与完全自包含的单文件 HTML。HTML 内嵌样式和必要数据，可离线搜索并按来源、审核状态和产业链筛选；收藏只使用浏览器本地存储，可直接打印或另存 PDF。每项保留证据链接、审核状态和生成时间；打开文件不需要 IntDog 后端、CDN 或网络脚本。

事实核验通过不等于成品可读。产物生成后运行独立确定性质量门：重点结论有证据；重点条目有具体中文概括、日期和来源；无空泛模板、占位符、异常短段落或重复段落；图表 sidecar 可解析且引用的数据存在；Markdown 链接、内部锚点和 HTML 筛选数据有效。失败项进入 `partial` 并列出机器可读原因，不得因文件可打开或格式齐全而标记研究成功。

## 数据与错误状态

页面只使用生成的 OpenAPI 类型。每个页面必须区分 loading、empty、partial、stale、error 和 ready。错误显示影响范围与下一步；后台运行不阻塞导航。

## 验收

- 新用户不编辑源码即可完成无模型首次流程，并能随后配置 CLI/API/MCP。
- 概览所有统计可导航到对应列表。
- Agent 断言与引用可读，来源检索与审查过程可追溯。
- 每日与周期窗口、排序、多选、删除恢复和产物阅读行为符合合同。
- 跨日动量显示可追溯到日观测；相比昨日和七日趋势不因重复转载或重复运行而变化。
- 便携 HTML 在禁网且后端关闭时仍能搜索、筛选、收藏和打印，且不包含外部脚本/CDN；Markdown 与 HTML 使用同一内容/证据清单。
- 成品质量门对缺证据、空泛/重复/占位内容、损坏 sidecar、坏链接和坏锚点给出确定 `partial`，与 Fact 核验状态分离。
- 周、月、季、半年、两年和五年使用平行直接生成按钮，不用隐藏在下拉菜单；按钮显示预计窗口、数据门槛、运行状态和最近成功时间。
- 键盘、焦点、语义标签、长中文/英文、空状态、窄屏和 200% 缩放有 DOM/可访问性证据。
- 浏览器/renderer 烟雾操作真实 UI，不使用仅 API 的假 GUI 验收。

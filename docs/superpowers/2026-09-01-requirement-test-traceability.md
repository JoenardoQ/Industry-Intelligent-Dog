# IntDog Requirements–Test Traceability Matrix

Date: 2026-09-01

## Test contract

The system boundary includes the Python/SQLite core, FastAPI/OpenAPI, React renderer, Electron/sidecar/background services, three-platform installers, and the GitHub release gate. Real user data, billing APIs, administrator-level attackers, signing, and notarization are outside the automated-testing boundary. Public credential-free network acceptance and real logged-in Agent acceptance are controlled external gates and cannot be replaced by mocks.

Meanings of status terms:

- `planned`: a clear test ID and oracle exist, but the test has not yet been implemented or executed;
- `implemented-unverified`: the test exists, but has not yet been fully executed on the current candidate revision;
- `external-gate`: must be executed in the specified native runner, on the public network, or in a logged-in Agent environment;
- `covered`: use only after the corresponding command and evidence pass on the current revision;
- `gap`: a decidable test, environment, or product decision is missing, so coverage cannot be claimed.

The current matrix is a pre-implementation plan. Every row is `planned`, `external-gate`, or an explicitly identified `gap`; it is not proof of passage.

## Applicability and remaining gaps

- Normal/exception, boundary, duplicate, out-of-order, state transition, recovery, concurrency, time, permission, dependency failure, resource limits, Schema, Unicode/timezone, accessibility, and native lifecycle all have matrix rows.
- Administrator/root, debugger, kernel, and physical-memory attacks are outside the product threat model. The documentation must state this exclusion explicitly; it cannot claim absolute memory wiping.
- The implementation of the semantic-support oracle still needs to be determined in the `AG-T02` RED phase. Regardless of whether rules, a model, or a combination is chosen, locator snippets must be saved, and the same generation call must not be the sole judge. Until this test passes, automatic acceptance remains disabled.
- `NOM-01`, real Agents, Windows/macOS/Linux native lifecycles, and GitHub idempotent readback all require external-environment evidence; local mocks, the reference harness, or historical releases cannot close these rows.
- The current revision has not yet implemented the planned tests above. Therefore, this matrix can only demonstrate that the plan is traceable; it cannot prove that the product is covered or releasable.

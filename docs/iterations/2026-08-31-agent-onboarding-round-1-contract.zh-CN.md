# Agent 与首次使用周期 · 第一轮实施合同

[English](2026-08-31-agent-onboarding-round-1-contract.md)

## 决策与边界

- 用户于 2026-08-31 选择提案 1、2、3、4。
- 目标是三平台可下载产品：首次启动可诊断、可建行业、可执行首个任务、可重开，且能连接或交接给国内外 Agent。
- 本轮不授权删除生产数据、真实付费调用、提交、push、CI 触发或发布。
- MCP 默认只读。Agent 结果必须先导入为待复核草稿，不能绕过用户确认直接写入事实库。

## 权威能力模型

一个后端 Manifest 统一维护 Agent 与 API Provider 的 ID、显示名、地区、连接方式、执行级别、公开命令、认证方式、Web 能力、默认模型/API Base 和文档链接。工厂仍使用显式 adapter map；未知直接执行 Provider 必须拒绝。API、调度和 UI 从 Manifest 派生，不再维护第二套选择清单。

## Agent Bridge 闭环

1. 首次设置显示 Codex、Claude、Work Buddy 和通用 MCP 配置，并支持复制。
2. 用户可导出某行业的任务包清单与单项 JSON 文件。
3. 任意 Agent 可离线执行任务并产生结果文件。
4. 导入端限制行业、任务 ID、路径、大小、Schema 和引用字段；结果以 `draft_review_required` 保存并写审计记录。
5. 导入不得覆盖原任务或事实库，不得接受绝对路径、路径穿越、未知任务、超限内容或未引用的断言。
6. 自定义 CLI Profile 只保存命令名与公开参数模板，不保存密钥，不经 shell 执行。

## 三平台产品门禁

Windows、macOS、Linux 的每个原生构建均须运行 Python 套件、Web DOM 测试、生产构建、OpenAPI 漂移、仓库检查、sidecar 烟雾和桌面 renderer 工作流。桌面工作流至少验证：首次向导可见、创建行业、首任务完成、任务中心可见、重开后行业仍存在。安全存储可用时，用虚拟 Key 验证加密保存/清除和无泄露。

## 风险覆盖模型

| ID | 风险 | 必须证据 |
| --- | --- | --- |
| C1 | 能力清单跨层漂移 | Manifest→API→调度→UI 集合契约测试 |
| C2 | 未就绪 Provider 仍入队 | 手动与自动任务均拒绝且无 Job |
| C3 | Agent 配置不可用 | 四类 MCP 配置结构、参数和复制 UI 测试 |
| C4 | 结果越界或污染事实库 | 穿越、绝对路径、未知任务、超限、坏 Schema、缺引用均拒绝 |
| C5 | 合规结果部分写入 | 原子写、草稿状态、审计、重复导入幂等测试 |
| C6 | 自定义命令注入 | argv 模板校验、禁止 shell 元字符/路径参数测试 |
| C7 | React 白屏但安装包通过 | renderer DOM 首次流程与重开持久化烟雾 |
| C8 | Key 泄露 | API/DOM/log/artifact 扫描和安全存储清除测试 |
| C9 | 文档与发行结论过期 | 双语结构对账；证据绑定源码 revision/diff |
| C10 | 旧客户端被破坏 | 既有 Provider ID、任务包和只读 MCP 回归测试 |

不把本地无 Chrome 或无三平台 runner 的结果称为原生 GUI 通过；这两项必须保留为发行阻断条件。

## 完成标准

- C1–C10 均有自动化证据或明确的原生阻断状态。
- 新用户无需编辑源码即可选择任务包、已登录 CLI 或安全 API 模式并创建第一个行业。
- 未内置 Agent 可通过配置/任务包完成交接；任何写回都待复核。
- 当前架构、状态、安装与发行文档中英文结构和语义一致。
- 本轮对账、测试、静态检查完成后才可关闭；随后才启用 Superpowers 进入最终轮。
